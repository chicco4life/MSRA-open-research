# Sources: How we researched our first six products

[`sources.csv`](sources.csv) lists every study cited in the [report](../README.md), numbered as in the report. Open it on GitHub for a searchable table.

| Column | Meaning |
|---|---|
| `ref` | Reference number in the report |
| `title`, `authors`, `journal`, `year` | The study |
| `pmid` / `doi` | PubMed ID and DOI |
| `pmc` | PubMed Central ID, present only when the full text is free to read |
| `studied_in` | What the study was actually done in (species, tissue, or humans) |
| `tags` | Species groups, separated by semicolons |
| `topic` | Short topic label |
| `used_for` | The MSRA product the study informs |

The studies belong to their authors and publishers. We link to them; we do not host copies.

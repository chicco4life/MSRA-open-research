# Research library

[`studies.csv`](studies.csv) lists the published studies we track. Open it on GitHub to see a searchable table.

| Column | Meaning |
|---|---|
| `title`, `authors`, `journal`, `year` | The study |
| `pmid` | PubMed ID, if it has one |
| `doi` | DOI, used when there is no PMID |
| `pmc` | PubMed Central ID. Present only when the full text is free to read |
| `studied_in` | What the study was actually done in (species, tissue, or humans) |
| `tags` | One or more of `Reptiles; Rabbits; Birds; Cats; Dogs; Other`, separated by semicolons |
| `topic` | Short topic label |
| `relevant_to` | The MSRA product or note it informs, if any |

Studies belong to their authors and publishers. We link to them; we do not host copies.
